# 实验接口兼容与安全边界

课程接口以官方 `2026-python/docs/oj/api.md` 和 Step 1–6 为基准。

- 受保护路由在 JSON 解析前检查 Session、禁用和管理员角色；损坏 JSON 不再覆盖 401/403。
- 密码至少 6 个字符，最多 72 个 UTF-8 字节，避免 bcrypt 静默截断。中文和 emoji 按编码字节计算。
- 旧超长密码必须由本机操作者运行 `uv run python scripts/reset_password.py USERNAME` 人工重设。
  命令交互读取并确认新密码，事务更新哈希且撤销目标用户全部 Session；不会输出密码或接受命令行密码。
  本次开发不会自动重设已有账号。
- 题目和人工草稿的难度字符串原值保存；标准等级只是 UI 建议，AI 完整生成仍要求标准等级。
- 课程提交、用户、访问审计列表允许超过 100 的页大小，保留缺省分页语义；巨大页码返回空列表。
- 按 Step 4 的统一权限说明，查询和登记评测语言均要求登录。
- 明确保留的扩展保护：唯一管理员不可被降权或禁用（409）；已删除题目的旧提交不可重测（409）；
  不安全语言命令拒绝执行；资源与上传大小设有安全边界。这些不宣称与官方文档零差异。

Streamlit 默认入口与 React 全量功能迁移将另行交付。当前兼容入口仍为 `scripts/run.ps1 -Legacy`
或 `scripts/run.sh --legacy`。真实模型历史验证不等同于本轮重新调用模型；本轮使用本地 mock。
