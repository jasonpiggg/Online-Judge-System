# Streamlit 管理整合与命题质量流程（2026-09-09）

本轮仅调整 Streamlit 和后端。管理员资源入口合并到管理中心，八个板块在原页面显示内容；
普通用户资源与后端权限保留。旧资源 URL 原地兼容。独立查询参数保存各板块筛选与页码，
主动打开草稿或提交详情后可返回来源。列表仅保留底部分页，用户分页位于表格之后、角色表单之前。
页面沿用 1200px 内容边距，分页总数、页码和跳转分组铺满行，窄屏换行。
参考题可展开选择或按题号、标题搜索；无参考题不依赖列表加载成功。

## 最新调整：质量与四分钟预算

用户在第一轮六次验收后要求恢复更完整的命题流程，不能用快速基础通过替代质量。
Streamlit 现在发送 `generation_mode=balanced`；原 `basic_draft` 保留，API 默认 `full` 兼容。
balanced 恢复题面与参考解、验证资产、独立复审、参考解执行、错误解卡错和独立随机对拍。
系统阶段策略仅影响 balanced：Flash high 生成题面/资产/定向修复，配置的 GLM-5.3 low 复审，
沿用该模型自己的费用快照和 JSON 兼容设置。个人配置仍优先，其他 AI 模块保持原流程。
没有配置 GLM-5.3 时保留现有端点模型，不虚构凭据或费率。

阶段上限：题面50秒、资产40秒、复审60秒、本地完整验证40秒、最多一次修复25秒、复验20秒，
最后预留5秒；全部服从含排队的240秒共同 deadline，首次生成扣除已用排队时间。
题面/资产最多8192输出 Token，复审/修复4096，并服从更低的配置和模型能力上限。
紧凑目标为8–12个针对性测试、20个小规模随机输入和两个不同的错误算法；不降低本地质量门禁。
约三分钟是工作量预算的参考，不通过 sleep 人为延迟，不承诺外部模型每次成功。
失败保留已观测费用及可恢复候选；不假称验证成功，不自动发布。补全仍可独立发起，保留版本保护。

界面增加管理内容模块框、功能标题、轻量网点品牌装饰、表单与折叠模块底色。
仍沿用原版全局边距，题面不增加额外宽缩进，移动端按组换行。
