# Atelier OJ 前端精修验收

## 范围与结构

保留蓝白品牌、中文系统字体、JetBrains Mono 和纵向做题顺序。本轮仅调整 React 展示、交互入口和样式，不更改 API、数据库、评测规则、依赖或旧 Streamlit 客户端。

`web/src/style.css` 改为样式入口，按以下顺序加载：

| 文件 | 职责 |
| --- | --- |
| `styles/tokens.css` | 字体、颜色、间距、圆角、控件及编辑器尺寸 |
| `styles/base.css` | 基础控件、焦点、表单、分页、步骤导航及减少动画支持 |
| `styles/components.css` | Markdown、语义状态、评测测试点、AI 差异、折叠区域等共用组件 |
| `styles/layout.css` | 主导航、已打开任务、页面容器、登录与手机导航 |
| `styles/pages.css` | 题库、纵向做题、提交记录、命题、账户和管理布局 |

删除旧的重复覆盖与 `.button.button` specificity 补丁。普通内容面去掉装饰阴影；导航以浅蓝和指示线表示选中，浮层保留阴影。后续样式应修改对应归属规则，不在入口或文件末尾追加同名补丁。

## 页面改动

- **全局**：任务区改称“已打开”；手机标签外框 46px、内部按钮至少 44px。主按钮、次要按钮和导航层级分离，统一可见键盘焦点。
- **题库**：数量与难度说明合并为紧凑工具行；长题号省略显示并保留完整 title；手机标题占整行，题号和状态纵向排列。
- **做题**：移除重复标题，编辑与删除归入“题目操作”，支持 Escape 关闭并恢复焦点。正文限制约 72ch；语言、代码导入与字号集中到工具行。提交与保存状态在编辑内容范围内吸底，不改变 Monaco 的保存、备份和冲突逻辑。
- **结果与提交**：压缩评测摘要，保留测试点、失败筛选和权限控制；提交详情提供“继续修改”。手机记录改为行式列表，结果、时间、详情与日志入口直接可见。
- **命题**：导入、示例下载和手动创建集中排列；草稿与任务使用文字加语义色徽章。来源／作者折叠，顶部提供 AI 辅助跳转；保存、验证、发布按当前阶段突出动作。
- **AI**：当前回答排在输入区之前，压缩上下文和状态容器；任务完成状态与打开草稿合并。保留费用、错误和恢复说明。
- **账户／资源／管理／登录**：账户信息、练习统计、模型、语言分组；退出独立放底部。日志查询先展示输入与动作；403／404 说明在对应错误时展示。管理页提供手机分类选择器、详情返回列表与独立危险操作区域；单页或空列表隐藏分页。登录／注册切换使用轻量选中态。

## 验证方法

自动浏览器测试使用 `scripts/serve_web_test.py` 创建的临时数据库、题库和模拟 AI 响应，不访问用户数据库，不产生真实模型费用。截图和 trace 保存在被 Git 忽略的 `web/test-results/`。

- `web/e2e/polish.spec.ts`：1440、1024、390、320px 下的顶部高度、完整标题宽度、标签点击区、菜单键盘操作、提交详情与日志入口；320px 下 AC／WA／CE／评测中、长题号、空记录和加载错误；AI 跳转保留未保存字段且不创建模型任务。
- `web/e2e/workflows.spec.ts`：核心页面截图扩展到 320px，继续覆盖草稿保存、预览、步骤切换、三种 AI 模式、差异采纳、验证发布、公开日志权限与管理员操作；断言回答位于输入区前。
- `web/e2e/refinement.spec.ts`：继续覆盖代码／JSON 导入、跨标签恢复、200% 缩放、长内容与手动滚动不中断。
- 前端：43 项 Playwright 流程通过；53 项单元测试、ESLint、TypeScript 与 Vite 构建通过。最终局部调整另行重跑 6 项精修验收。
- 后端：255 passed、10 skipped（Windows 上跳过 Linux 专属检查）；Ruff、mypy 与覆盖率门槛通过，line 95.20%、branch 87.86%。Linux 专属检查由 GitHub CI 执行。
- 关键文字配色计算：正文／白底 14.62:1，次要文字／白底 5.03:1，次要文字／浅色面 4.73:1，品牌蓝／白底 5.17:1；AC、WA、CE、评测中徽章文字均大于 4.5:1。这是关键配色与交互检查，不等同于完整 WCAG 认证。

保留现有 Monaco 大体积 chunk 构建提示，本轮不扩大到依赖升级或拆包。浏览器自动验收以 Chromium 为准；真实模型提供商行为及其他浏览器没有新增验证。
