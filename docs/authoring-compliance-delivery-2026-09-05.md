# OJ 命题管理、代码覆盖与实验合规交付报告

记录日期：2026-09-05。核对基准为课程官方 `2026-python/docs/oj/api.md` 和本轮提供的助教答疑。

## 1. 页面交互与编辑器

- 做题页 Monaco 初始字号改为 14px，保留 14/16/18/20/24 五档手动选项，正文和 UI 字号未联动修改。
- 新增统一的用户操作定位 Hook。资源题目详情、管理员用户资料、测试点详情、草稿步骤修复入口、资源与管理标签切换会平滑定位并聚焦一次；系统启用“减少动态效果”时改为即时定位。
- 定位只由点击触发，AI 流、评测轮询、数据刷新、深链接和浏览器前进后退不会触发重复滚动。

## 2. 命题中心分页与归档

- “我的草稿”和“AI 任务”分别使用 URL 参数 `draft_page`、`task_page`，每页 10 条，共用首页、尾页、前后页和周边 5 页分页器。
- 草稿和任务均提供归档确认；归档后自动刷新并收缩到有效页。活动标签同步移除，但数据、版本和费用保留。
- 草稿归档前停止关联的运行任务；AI 任务归档前实际取消上游调用。`archived_at`、恢复草稿关联和索引由数据库 v8 增量迁移加入，升级前保留备份。
- 新列表参数返回带 `total/page/page_size` 的 metadata；不带新参数的旧客户端仍收到原数组。任务 DELETE 对创建者/管理员开放且幂等。

## 3. AI 代码候选与覆盖

- 完成状态回答中的每个有效语言代码围栏都会单独显示“查看代码候选 N 差异”，日志、纯文本、JSON、Shell 和 Diff 围栏不会误判为可覆盖代码。
- Diff 始终以点击时的当前编辑器内容为基线。语言不同、疑似片段、内容相同或会删除大部分代码时显示警告，但允许继续审查。
- 用户必须在 Diff 后再次点击“确认覆盖编辑器”。若期间代码或语言变化，确认按钮停用，必须重新打开 Diff。
- 覆盖保存原代码并提供撤销；用户继续编辑或切换语言后，旧撤销停用，避免覆盖后续修改。流式、失败和取消任务不提供覆盖入口。

## 4. 实验文档与权限合规

- 提交限频改为同一用户、同一道题每分钟最多 3 次，并由 intake lock 保证并发准确；不同用户或不同题目独立计数。
- 删除题目时原子阻止新提交并标记历史提交 `problem_deleted`。历史记录和源码保留，但不再计入 `submit_count`、`resolve_count` 或题库进度；重建同题号不会恢复旧成绩，旧提交不能重测，网页也禁用继续做题和重测入口。
- `resolve_count` 继续按用户+题目去重，`submit_count` 只统计未删除题目的每次有效提交。
- 提交列表在两个一级条件都为空时返回 400；管理员必须显式使用 `all_users=true` 才进入全站模式。访问审计同样要求用户或题号至少一项，网页无筛选时不发送请求。
- 普通用户网页覆盖题目列表/详情/新增/编辑、语言查询/登记、提交、本人详情/日志和公开日志。管理员另覆盖删题、全站提交、重测、日志公开、用户与角色、访问/角色审计和重置。
- 动态语言只登记安全命令模板，不安装工具链；页面明确提示先预装运行环境，并说明已有 gcc 可动态登记 C。

## 6. AI 命题失败与成果恢复

- AI 结果在完整验证前和失败后保持 v2 `candidate` 信封，失败信息写入 `validation`，不再用无 `kind` 的验证对象覆盖候选。
- 唯一一次自动修复按失败类型限定字段：错误解只改对应错误解和必要测试；生成器只改生成器；oracle/参考解只改受影响资产；结构和排版只改反馈字段。服务端拒绝越界 Patch。
- 新增 `POST /api/ai/problem-tasks/{id}/save-draft`。失败或取消任务的创建者可零费用恢复题面、样例、测试、解法和审查内容；不合格字段会舍弃并列出缺失字段。重复保存返回同一草稿，不覆盖来源草稿。
- 失败页展示失败阶段、检查信息和已保存字段，提供“返回原草稿”“将当前成果另存为草稿”“从已完成阶段继续”。恢复草稿明确为未验证，不能绕过基础检查或完整门禁。
- mock 已复现错误解未卡错、生成器数量错误、修复 JSON 截断、取消和重复保存。真实模型使用临时数据库生成“简易计算器”：任务完成，12 个固定测试点、3 个错误解均被卡错、60 组 oracle 对拍通过、mutation score 100%，未使用修复；输入 5,805、输出 3,202、合计 9,007 Token，服务商计费记录为 CNY 0.123424。该题未发布到正式题库。

## 已知限制

- Windows 自动测试跳过 Linux 专属资源隔离用例；CI 会在 Ubuntu 重新执行。
- 真实模型验收只证明本次配置和题目通过，不能代表所有需求都不会触发模型结构或质量失败；失败成果恢复路径用于保留可用工作并支持人工修正。
