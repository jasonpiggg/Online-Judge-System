# 新版前端与 AI 工作流

默认入口为 `http://127.0.0.1:8000`。首次安装使用 Node 24 在 `web/` 执行
`npm ci && npm run build`；日常一键启动只运行本机 Python 和已构建页面。
Streamlit 保留在 `8501`，通过 `scripts/run.ps1 -Legacy` 或 `scripts/run.sh --legacy` 启用。
没有外部部署，也不迁移或删除现有题库和提交。

## 操作

- 题库筛选与分页写入 URL，标题进入题目。上下题遵循进入时的筛选集合；返回题库恢复筛选和滚动。
- 做题采用白底分栏，分隔条可拖动或用左右方向键操作；小屏使用题目、代码、结果、AI 标签。
- Monaco 支持语言、字号、Ctrl/Cmd+Enter 提交；评测结果就地展示。提交详情可以返回题目继续修改。
- 代码按账户、题号、语言保存，发送 `expected_revision`。本机备份保留未同步代码；409 展示双方版本供选择。
- 命题中心提供草稿、AI 任务、手动创建。题目页的“题目操作”进入编辑。草稿分题面、测试、发布三个步骤。
- 所有发布仍通过原有质量门禁；手工完成验证资产后可运行本地验证，无需模型调用。
- Markdown 阅读和预览共用组件，支持 GFM、公式和高亮；原始 HTML 禁用，代码、样例和日志保留原文。
- AI 助手先展示当前代码/题目上下文摘要，默认逐步提示；代码建议对照当前版本后由用户应用。
- 账户设置提供个人模型；管理员入口提供用户、语言、审计和系统维护。旧权限由后端继续执行。

## API 与持久化

`GET /api/auth/me` 查询登录账户；浏览器写请求校验 Origin 和 Sec-Fetch-Site，保留无 Origin 的旧 API 客户端。
FastAPI 提供 SPA 深链接；未知 `/api` 路径继续返回 API 404，资源缺失不会误返回 HTML。
数据库增量升级到 v6，升级前保留自动备份。新增会话、任务上下文和幂等映射；
一条助手消息与一个任务共用持久化记录，避免消息和任务分别插入导致重复。

新增 `/api/ai/conversations/`、`/api/ai/conversations/{id}/messages`、
`/api/ai/assistant-tasks/{id}`、`/api/ai/assistant-tasks/{id}/cancel`；
命题任务和助手任务均提供 `/{id}/events` SSE。
SSE 包含带序号的 stage、preview、delta、usage 和终态事件；每条携带完整任务快照，
重连直接返回最新持久化快照（无事件日志游标保留窗口）。流断开时前端回退轮询，终态停止。
预览只提取完整 JSON 字段，模型内部推理不展示。模型输出与用量按既有节流周期合并写入。

同用户同 `Idempotency-Key` 与请求内容返回原任务，不同内容返回 409；不同 key 的相同活动上下文也复用任务。
默认用户最多 2 个活动任务、单进程最多 4 个上游连接。启动脚本使用单进程；
多 worker 部署需外部队列与分布式锁，不在本轮本机交付范围内。
取消会关闭上游连接、保留已观察用量；重启将进行中任务标记中断，不重放付费调用。

## AI 协议与预算

协议版本 `oj-2026-09-v2`：完整命题依次生成题面/参考解、测试/独立 oracle/生成器/错误解、复审补丁。
仍执行参考解评测、错误解检测、oracle 对拍。确定性格式或验证失败最多一次定向修复；
认证、429、网络中断、超时不会自动再付费调用。中断任务保留已完成阶段，可显式继续失败部分。
局部修改仅返回白名单字段，采纳使原验证失效；审查只返回意见。
新客户端发送 `workflow_version: 2`；旧调用默认保留原协议。

不改动本地 `.env` 的完整命题 65,536 与局部 16,384 Token 配置；助手默认 16,384。
可通过 `OJ_AI_MODEL_OUTPUT_LIMITS` 指定精确模型名的能力上限，任务开始时冻结；
已知 GPT-4o 上限来自[官方模型文档](https://developers.openai.com/api/docs/models/gpt-4o)，
未知模型名不猜测能力，使用配置预算，服务端错误不会自动重试。
助手上下文只含白名单题面、当前代码、本人提交摘要和有限历史，不包含隐藏测试或其他用户代码。
当前内容超过容量时拒绝请求并提示缩小范围，不静默截断代码。
