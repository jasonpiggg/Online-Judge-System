# 全站排版、任务标签与验证体验升级报告

本报告逐项对应《OJ 全站排版、任务标签与验证体验升级》计划。实现日期为 2026-09-05。

## 1. 视觉与交互统一

- 正文通过 `--font-body: 16px` 恢复为 16px；导航、按钮、表格、徽章和辅助文字使用独立的 `--font-ui: 14px`，不会随正文一起放大。
- 全站补齐页面区块、表单行、工具栏、编辑器、评测和 AI 面板间距。桌面和手机继续使用紧凑布局，但相邻控件不重叠、不贴边。
- 页面统一使用浅灰蓝容器、细边框、轻阴影、标题图标底板及低强度强调色，并保留白色主背景。
- `BackLink` 统一替换题库、提交和命题页面的纯文本箭头，包含 Chevron、目标名称以及 Hover/Focus 反馈。
- 1440px、1024px、390px 三档真实浏览器场景检查 Sticky 导航、折行和页面横向溢出。

## 2. 浏览器式进行中任务标签

- `ActivityProvider` 在主导航下方维护题目、草稿、提交、AI 命题和本地验证入口；数据按用户 ID 隔离保存在浏览器本地，最多保留 20 项。
- 每项显示类型图标、短标题、状态点和关闭按钮。首屏展示最近 6 项，其余收进可键盘操作的“更多”菜单。
- 关闭只删除快捷入口。关闭当前项后进入最近任务或所属列表页；重新进入页面会重新加入。
- 工作区和命题编辑器会把备份失败、版本冲突标记为不安全关闭；只有这些情况才显示确认，确认文案说明内容仍会保留。
- 运行中的服务器 AI 任务不会因关闭入口而取消，可从命题中心任务历史恢复。

## 3. 草稿差异、键盘操作与错误提示

- `DiffView` 为 AI 局部修改提供桌面并排和移动端单列模式；题面使用词级增删，样例、测试、代码与 JSON 使用行级增删。绿色表示新增、红色表示删除，可展开未修改字段。
- 做题助手支持 Enter 发送、Shift+Enter 换行，并忽略中文输入法组合状态；命题长文本支持 Ctrl/Cmd+Enter，单行 AI 修改要求支持 Enter。
- `ErrorNotice` 统一显示发生的情况、建议操作和默认折叠的技术详情。后端保持 `code/msg/data`，并可选返回错误标识、标题、建议、字段错误及是否可重试。
- 评测结果针对 WA、CE、RE、TLE、MLE、系统错误提供自然语言排查方向，不展示隐藏输入、密钥或服务器内部路径。

## 4. 分层本地验证与权限补齐

- `/api/problem-drafts/{id}/verify` 接受 `basic` 与 `full`；无请求体仍执行旧版完整验证。
- 基础检查覆盖 Schema、题号、限制、样例/测试格式及 Markdown/LaTeX。有参考解时实际运行全部样例和测试；没有参考解时明确警告“未执行参考解校验”，仍允许发布手工题。
- 完整验证继续要求至少 5 个唯一测试点、2–4 个错误解、独立 oracle、20–100 组唯一随机输入、参考解对拍一致和 100% 卡错。
- 草稿记录验证等级、检查项、警告及对应 revision。任何人工编辑都会清除旧验证结论、恢复 draft 状态并重新阻止发布。
- 权限保持课程定义：普通用户可创建/编辑题目、注册语言、提交、查看自己的提交和逐点日志；公开日志后，其他登录用户只能读取逐点状态。管理员专属功能继续包括删题、公开日志、全站提交、跨用户详情、重测、角色、审计和重置。
- “资源 → 公开日志”新增受限查看链路。页面只调用既有日志接口，不请求或显示他人提交概要、源码、隐藏输入和标准输出。

## 5. 验收与交付证据

- 组件测试覆盖任务标签关闭和不安全确认、差异布局、统一返回控件、错误提示、分页边界、IME、Markdown/KaTeX 与评测摘要。
- 后端测试覆盖无参考解基础发布、错误参考解、完整验证兼容、编辑后验证失效、并发 revision 保护、结构化错误和日志权限矩阵。
- 20 条 Playwright 流程覆盖主路径、三档响应式尺寸、AI 差异、任务标签、基础检查修复入口、公开日志源码隔离及管理员深分页。
- 全量命令、覆盖率、提交、PR、自动审查和 CI 的最终状态记录在本轮 PR 与交付回复中。

外部真实模型供应商没有可用用户密钥，本轮没有制造“真实调用成功”记录。现有 HTTP/SSE mock 用于验证协议、恢复、取消和错误路径；它不能证明任意外部模型的内容质量。
